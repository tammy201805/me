数字钥匙售后知识中心

AI 预诊 + RAG 知识库｜把分散的排查经验沉淀为知识库，帮二线支持快速定位故障根因

负责：需求定义 / 成功指标 / RAG 与预诊链路 / 评测 / AI 协同开发

82%前 3 根因命中率
上线门槛 ≥60%，知识覆盖上限 84%
94%预诊方案正确率
2.84s重排延迟 P95

100 张合成工单端到端评测（含 16 张无答案单，检验拒答），DeepSeek + Jev 真实调用。

CONTEXT

背景与目标

数字钥匙故障横跨云端、车端与手机端，排查经验散落在工单和个人记录里。二线既要快速找到相似问题，也要判断知识是否适用于当前主机厂、车型与版本。

目标：给出有来源的候选根因与方案，并让关单经验持续沉淀为知识。

KEY DECISIONS

方案与取舍

  • 不做自主 Agent，用固定流程。混合检索 → 重排 → 置信度分档；分流规则与置信度由程序计算，主机厂数据隔离由代码保证，换模型前后效果可直接对比。
  • 先定门槛，再做评测。上线门槛定为前 3 命中率 ≥60%；评测集刻意放入无答案单，检验系统会不会“不懂装懂”。
  • 知识治理形成闭环。知识标注适用范围、审核后发布；关单自动生成知识草稿，badcase 回流迭代。

生命演化模拟器

多模态 AIGC 短视频 Agent｜文本一键生成“物体生命演化”科普短片

负责：产品定义 / 工作流与 Prompt 设计 / 评测与成本控制

1.3k+单月生成视频
88.7%云端出片成功率
6–8 元单条成本 · 端到端约 3 分钟

CONTEXT

背景与目标

科普、知识类短视频与品牌溯源内容，需要人工查资料、写脚本、生成画面再剪辑。单次调用模型难以保证阶段衔接和画面一致，失败后整条重跑成本高。

目标：用户输入一句话，自动完成从脚本到成片。

KEY DECISIONS

方案与取舍

  • 固定工作流 + 大模型决策点。模型只做意图识别、阶段拆分与提示词生成；流程、重试与拼接交给代码，保证可控、成本可预测。严重歧义先反问澄清。
  • 一致性靠结构约束。全局风格与阶段提示词分离，用阶段衔接规则约束前后形态、背景与光影。
  • 评测与兜底。自建评测集与回归集；单段失败只重跑该段，按视频时长分档控制单条成本，成片加 AI 生成内容标识。

03内部自用工具2026.05

LLM Eval 评估工作台

从“感觉回答不错”，到有依据的版本比较与发版判断

为交付项目搭建的统一评估工具，串起 错误分析 → 失败分类 → 代码断言 → LLM 评委 → 评委校准 → 版本对比与发版门禁；换模型、改提示词后先跑回归对比，过了门禁才发版。

  • 按失败类型选评估方式：格式、工具调用等确定性问题写成代码断言；政策一致性等主观判断交给单维度 LLM 评委。
  • 评委也要被评估：用人工标签算 TPR / TNR 与置信区间校准评委，再逐题比较新旧版本，回归即阻断发版。

知应 AI 助手

企业与高校 AI 智能助手定制（RAG）｜用机构自有资料回答高频咨询，答不了的转人工

负责：产品设计 / 开发 / 交付上线

2 家已交付高校 / 企业
2k+ 次单客户累计问答量
约 50%人工咨询量下降

高校招生、校务与企业客服咨询量大、问题重复，人工答复慢、口径不一。为机构搭建专属 AI 助手，全天候自助答复，答不了的平滑转人工。

  • 先划 AI 边界：只答“高频、有标准答案、错答代价可控”的咨询；办理、审批、个人信息查询一律转人工。
  • 宁可少答，不乱答：回答可附出处，检索不到可靠依据就明确告知；转人工时 AI 暂停应答并生成交接摘要，用户不必重复描述；各机构知识与会话隔离。
  • 达标才上线：用客户真实咨询问题建评测集，含资料外问题检验拒答；设准确率、拒答率两道门槛，上线后未命中与转人工问题回流补充知识库。
